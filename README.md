# Multi-Servicios MYK

Landing page one-page para Fontanería Express e Intervenciones Eléctricas Básicas en el Día.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Producción

```bash
pnpm build
```

La salida lista para Netlify/Vercel se genera en `dist/public`.

## WhatsApp

El formulario construye una URL `wa.me` dinámica con servicio, urgencia, zona y detalle, dirigida al número `+59896189551`. También incluye un CTA flotante visible en todo momento.
